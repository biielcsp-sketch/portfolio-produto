## Como eu trabalho

Resumo do meu processo, com exemplos reais: [Como eu trabalho](como-eu-trabalho.md).

- **Começo pelo problema real**, na operação, com quem usa.
- **Defino o que fica de fora** tanto quanto o que entra. Meus MVPs têm uma lista explícita de "não implementar agora".
- **Escrevo o produto antes de construí-lo**: perfis, regras, jornadas e critérios de aceitação.
- **Dirijo o desenvolvimento com IA** usando agentes especializados, revisão obrigatória e testes de regressão.
- **Aprendo com o uso**: ajusto o produto a partir do feedback de quem opera.
